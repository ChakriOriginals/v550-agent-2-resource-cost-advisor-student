# Student Setup Guide

1. Download or clone this repository into a folder you control.
2. Open a terminal in the repository.
3. Run `python3 tools/verify_package.py`.
4. Run `python3 install.py`.
5. Restart Codex if it was already open.
6. Run `./start-v550.sh`, or open the folder in Codex Desktop.
7. Invoke `$v550-agent-2-resource-cost-advisor-student`.
8. Read the local privacy notice and answer only when you understand it.
9. Upload the final approved WBS created in Agent 1.

Keep the original WBS unchanged. The advisor will preserve its identifiers, parent links, deliverable links, approved-scope status, and PRE_VOTE or POST_VOTE labels.
